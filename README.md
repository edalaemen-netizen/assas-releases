# Assas : téléchargements

Installateurs de l'application **Assas**, pré-dimensionnement structurel automatique (BAEL 91 / EC2, RPS 2000, NV 65).

👉 **[Télécharger la dernière version](https://github.com/edalaemen-netizen/assas-releases/releases/latest)**

| Système | Fichier |
|---|---|
| Windows | `Assas-Setup-<version>.exe` |
| macOS | `Assas-<version>-arm64.dmg` |
| Linux | `Assas-<version>-x86_64.AppImage` |

Une fois installée, l'application se met à jour toute seule.

> Pré-dimensionnement automatique indicatif, à faire valider par un ingénieur structure et un bureau de contrôle avant exécution.
